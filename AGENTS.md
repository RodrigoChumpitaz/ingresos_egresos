# Ingresos y Egresos (`finanza.`)

Aplicación web de finanzas personales para control de ingresos, egresos, ahorro neto, metas de ahorro y visualización multi-divisa (`PEN` como moneda base).

- `backend/`: API REST en TypeScript + Express 5 + Mongoose / InMemory con arquitectura hexagonal.
- `frontend/`: SPA en React + TypeScript + Vite + Tailwind CSS + `shadcn/ui` + Recharts.

## Agent skills
